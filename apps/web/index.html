      How this works
      
      
        
        
      1. 
          The server decides everything. It steps the world 30 times a second from everyone's
          inputs — a direction, an aim, a trigger, never a position.
          ADR-0001
        
        2. 
        
      2. 
          Your tank is predicted. The page runs the server's own simulation on your input at
          once and corrects it when the server answers. The white ghost is where the server last
          said you were: the gap is your latency, hidden.
        
        3. 
        
      3. 
          Everyone else is interpolated about 100 ms in the past, between two snapshots that
          both arrived. Their ghosts are the newest snapshot: ahead of them, not behind.
        
        4. 
        
      4. 
          Shells are fast-forwarded, not targets rewound. Your shell starts on the server
          where your screen drew it, and only the server says what it hit.
          ADR-0002
        
        5. 
        
      5. 
          The wire is bytes on one WebSocket: snapshots as deltas, each shell sent once and
          flown by the same code on both ends.
          ADR-0003
          ·
          protocol
        
        6. 
      
      
      
      
        The lab makes your own link worse on the server's side of the socket — nobody else's.
